## 확인한 플랫폼과 원인

- 브라우저 게임: Rust `bevy_ecs` 시뮬레이터를 WASM으로 컴파일하고 React가 표시한다.
  웹 빌드는 Vinext 1.0.0-beta.2 / Vite 8.0.13 / Cloudflare Vite plugin을 사용한다.
  Sites 프로젝트 ID와 Worker 패키지가 있다. 네이티브 PC·모바일·콘솔 빌드 설정은 없다.
- 기존 상위/프로젝트 AGENTS.md와 CI 정의는 없었다. README, npm scripts, Cargo 설정,
  Vite/Cloudflare 설정, 테스트, Git 태그·최근 이력을 확인했다. 출시 태그가 없다는
  이유로 미출시라고 판단하지 않았으며 원격 출시 상태는 확인하지 않았다.
- 최초 `du -sk .`: **660,212KiB (644.738MiB)**. `node_modules` 493,720KiB,
  `.git` 157,056KiB, `dist` 4,916KiB, `public` 3,424KiB이다.
- 최대 파일은 필수 Cloudflare `workerd` 실행 파일 111,865,464바이트다.
  `public/og.png`는 2,319,477바이트이며 WASM 포함 전체 원본 `public`은 약 3.34MiB다.
  원본 에셋 대형화나 반복 패키지 복제가 주된 용량 원인은 아니다.
- `node_modules/.vite`는 optimizer 메타데이터가 원본 의존성을 가리키는 재생성 가능한
  개발 번들/소스맵 캐시다. ` 2`가 붙은 복제 파일도 있으며 삭제 목록 내 동일 SHA-256
  중복분은 **6,807,552 할당 바이트**다. 이름만으로 판단하지 않고 메타데이터와 해시를
  확인했다. 복제 생성 주체까지는 확인되지 않았으며 기존 빌드 스크립트에 날짜별 복제는 없다.
- 여러 `esbuild` 및 `lightningcss` 바이너리는 각각 Wrangler/Drizzle/Vite/Tailwind의
  서로 다른 고정 버전 의존성이다 (`npm ls` 확인). 단순 중복으로 삭제하지 않았다.

## 자동화와 검증

`scripts/build_lifecycle.py`를 npm의 웹 빌드·엔진 빌드·시작 및 신규 GitHub CI에 연결했다.
작업별 소유 표식/잠금, 자식 프로세스 그룹 보호, 신호 종료, 강제 종료 후 회수,
검증 후 게시와 복구 저널, 개발 패키지 각 2개·원문 로그 전체 10개/각 1MiB 제한을 구현했다.
출시 보관본·초기 배포본·심볼은 자동 개수 제한에서 제외한다.
새 [AGENTS.md](../../AGENTS.md)와 [정책/예외 문서](../build-cleanup.md)에 지속 규칙을 남겼다.

- 정리 테스트 **13개 통과**: 성공·실패·3개 종료 신호·무응답 자식 종료·부모 SIGKILL 및
  살아 있는 자식 보호·동시 작업·읽기 잠금·게시 중단/IO 오류 복원·개수/로그 크기 제한·
  출시/심볼 보존·엔진 원본 변경 감지·알 수 없는 소유권/심볼릭 링크·삭제 실패 경고.
- 실제 웹 빌드 성공 및 단계 내 HTML/WASM 검증 **3개 통과**. 게시된 위치에서도 3개 재검증.
  `npm start` 경로의 로컬 HTTP **200/게임 내용** 확인, 서버 종료 후 작업 폴더 **0개**.
- 첫 웹 빌드는 복사된 폰트 캐시의 절대 경로가 맞지 않아 검증에서 거부했다.
  작업 사본 CSS 경로만 보정해 해결했다. 원본 폰트 바이트/품질/출시 설정은 바꾸지 않았다.
  최초 실패 시 기존 `dist`는 유지되었고 실패 작업은 제거되었다.
- 원본·기존 배포본 등 **173개 파일 SHA-256 일치**, lint 및 `git diff --check` 통과.
  요약과 실행하지 않은 경로는 [validation.json](validation.json)에 기록했다.
- **미실행**: 원격 GitHub Ubuntu CI, 전체 Cargo/wasm-bindgen 재컴파일, 원격 Sites 배포,
  실제 전원 차단. Rust 엔진은 커밋된 WASM의 실제 동작으로 확인했고 엔진 게시/정리는
  작은 파일 fixture로 검증했다. 프로젝트에 정의되지 않은 네이티브 플랫폼을 검증했다고
  주장하지 않는다. 기존 정상 배포본의 출시/패치/롤백 필요성은 미확정으로 계속 보존한다.
